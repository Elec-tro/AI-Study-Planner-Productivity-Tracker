# FocusFlow – AI Study Planner

## 📌 Overview
FocusFlow is an AI-powered study planner that helps students organize tasks, manage time efficiently, and track productivity. It dynamically generates optimized schedules based on deadlines, difficulty, and available study hours.

---

## 🚀 Features
- 📅 Smart task scheduling based on priority and deadlines  
- 📊 Productivity tracking with visual analytics  
- 🔄 Auto-adjust schedule when tasks are missed  
- ⏱️ Pomodoro timer for focused study sessions  
- 🔥 Streak tracking system  
- 🌙 Dark mode support  

---

## 🧠 How It Works
- Users input subjects, tasks, deadlines, and available study hours  
- The system assigns priorities using a scheduling algorithm  
- Tasks are distributed across days to maximize efficiency  

---

## 🛠️ Tech Stack
- Frontend: React.js  
- Backend: Node.js / Flask  
- Database: MongoDB / SQLite
